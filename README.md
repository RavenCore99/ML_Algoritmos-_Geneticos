# Ejercicio 2 - Optimización multivariable

**Integrante:** (tu nombre)

## Descripción

Se modifica el cromosoma binario para soportar dos variables (x, y). La cadena se divide en dos mitades: los primeros 4 bits codifican x y los últimos 4 bits codifican y, cada mitad decodificada al rango [-5, 5].

## Función objetivo

Minimizar f(x, y) = x² + y², usando -f(x, y) como aptitud para convertir la minimización en un problema de maximización.

## Resultado

El algoritmo converge cerca del óptimo teórico (0, 0), donde f(x, y) = 0.
